# Changelog

## 0.1.0 — first public version

- Drag + Shift wheel for File Explorer and the Desktop; Shift cycles wheels, Esc cancels.
- Hotkey (Ctrl + Alt + Space) for selected files, right-click "Spinfix…", Send to, tray.
- Images: convert (JPG, PNG, WEBP, PDF, TIFF, BMP, GIF; HEIC/AVIF input), compress,
  compress to a target size, resize, remove info / location, several images → one PDF.
- Editors: Crop, Edit, Annotate, Redact (pixels really destroyed), Add background.
- PDF: to JPG/PNG, to text, merge, split, pick pages, rotate, compress, compress to size.
- Video/audio (with FFmpeg): MP3/M4A/WAV, WhatsApp 16 MB / Email 25 MB / 100 MB.
- Copy text from images (Windows OCR), copy path, copy file, zip, safe unzip.
- Toast with progress, Open, Show in folder, Undo (Recycle Bin), Cancel.
- Settings, first-run welcome, per-user installer and portable zip, `--self-test`.
- Security: magic-byte checks, atomic writes, never overwrites, zip-slip / zip-bomb /
  pixel-bomb limits, current-user-only IPC, no network access.
